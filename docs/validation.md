# v0.1.0 验收记录

自动化检查与人工视觉验收分开记录。未测试的环境不计为通过。

## 自动化覆盖

- 参数语法、错误码、UTF-8 重定向帮助和错误。
- EXE 参数真实往返：空参数、中文、空格、引号、反斜杠及换行。
- 工作目录、继承环境、NUL 输入 EOF、目标无控制台。
- 默认使用目标 EXE、BAT、CMD、PS1 所在目录；显式 `--cwd` 覆盖默认值。目标优先语法和旧语法拒绝。
- 目标查找、`--cwd` 中的裸文件名、`.exe` 补全、PATH、无效目标及工作目录；临时测试文件拒绝当前账户执行时返回访问拒绝错误。
- 启动器先退出，目标继续完成延迟任务。
- BAT/CMD 中文路径和参数、空参数、不安全路径和元字符拒绝。
- PS1 启动、参数、执行策略阻止时不绕过策略。
- CMD、Windows PowerShell、PowerShell 7 的管道/重定向与退出码。

## 环境与结果

最近验证日期：2026-11-16。

| 项目 | 本机结果 |
|---|---|
| 操作系统 | Windows 10 Pro for Workstations 22H2 x64，19045.6466 |
| 编译工具 | MSVC 19.51，Windows SDK 10.0.26100.0，CMake + Ninja |
| Debug / Release | 均构建成功；各 3 组 CTest 测试通过 |
| 终端 | CMD、Windows PowerShell 5.1.19041.6456、PowerShell 7.6.10 |
| Windows 11 | 尚未实测 |
| EXE 格式及依赖 | x64、Windows GUI 子系统；仅依赖系统 SHELL32.dll 和 KERNEL32.dll，无动态 MSVC 运行库依赖 |

测试框架仅在独立测试进程中设置执行策略环境变量，验证 RemoteSigned 和 Restricted 行为，不修改用户或机器执行策略。组织策略覆盖这些设置时，测试可能失败，需要按实际策略说明原因。

## 尚待人工或独立环境验收

- Windows 11 x64 实机或虚拟机回归。
- 无开发工具的干净 Windows 机器上解压运行。
- 资源管理器双击、快捷方式、交互终端启动的全程无黑框视觉检查。
- 具体 GUI 软件的初始窗口隐藏行为。
- 多账户运行环境回归（当前账户的执行权限拒绝已自动化测试）。

静态链接和依赖检查不能替代干净机器验收；目标无控制台的自动化断言不能替代所有入口的视觉验收。
